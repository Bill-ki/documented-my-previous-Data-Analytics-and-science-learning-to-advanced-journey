# documented-m# My Data Analytics & Data Science Learning Journey (2024–2025)

## Overview

This repository documents my learning and practical development in Data Analytics, Business Intelligence and Data Science during my SIWES 1 (2024) and SIWES 2 (2025) training at Nascomsoft Embedded, alongside my independent learning and continuous skills development through online resources, particularly YouTube.

Throughout this learning period, I explored different tools, techniques and approaches to working with data, from spreadsheet operations and data cleaning to database querying, programming and data visualization. My learning involved tutorials, assignments, practical exercises, dataset exploration and projects that helped me develop a better understanding of how data can be processed, analysed and presented.

This repository contains numerous datasets, exercises, Excel workbooks, Power BI reports, SQL scripts, Python practice files and learning materials gathered and worked on throughout this period.

### Microsoft Excel – Data Analysis and Spreadsheet Management

I developed practical skills in Microsoft Excel and explored its application in data preparation, analysis, reporting and spreadsheet management.

- Data manipulation and organisation.
- PivotTables and PivotCharts.
- Data validation.
- What-If Analysis.
- Data summarisation and reporting.

I learned how to work with Power BI for data exploration, visualization and reporting. Through exercises and practical reports, I explored how datasets can be transformed into visual representations that support data interpretation and reporting.

My learning included:

- Importing and exploring datasets.
- Data visualization.
- Creating charts, tables and report visuals.
- Dashboard and report development.
- Presenting data in a structured and visual format.
- Exploring datasets across different subject areas.

### SQL – Database Querying and Data Exploration

My SQL learning focused on understanding how to interact with databases, retrieve information and perform data-related operations using queries.

Topics explored included:

- Writing SQL queries.
- Retrieving and filtering records.
- Sorting and grouping data.
- Aggregate functions.
- Data exploration through queries.
- Analysing datasets using SQL.

### Python – Programming and Data Science Foundations

I explored Python programming as part of my technical development and introduction to Data Science and programming-based approaches to working with data.

My learning and practice included:

- Python programming fundamentals.
- Writing and executing Python code.
- Basic programming logic.
- Practical coding exercises.
- Exploring Python as a tool for data-related tasks.
